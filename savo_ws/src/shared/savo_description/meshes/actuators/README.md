# Actuator meshes

Place visual meshes for the drivetrain and pan-tilt actuators in this folder.
Recommended filenames are:

- `dc_motor.stl`
- `pan_servo.stl`
- `tilt_servo.stl`
- `pantilt_bracket.stl`

One mesh may be reused for every physically identical component. STL files
must document their source units, coordinate orientation, origin, and license.
Prefer detailed meshes for URDF visuals and simple primitive collision geometry.
